## 1. Implemented behavior with concrete scenarios

- Immediate stable echo: send creates one UUID, persists the outbox entry, renders the production bubble synchronously, then posts. New-chat creation shares one idempotent `new-{uuid}` key plus a persisted mapping; a crash cannot fork chats.
- Delivery states: sending (with memory-only honesty), saved (quiet), failed (reason + same-UUID Retry attached to the bubble, always visible in `.otis-delivery`, never hover-gated). Editing failed content sends a new UUID. Lost acknowledgment resolves by replaying the same identity; server dedupe prevents a second run.
- Prompt dispatch: acceptance publishes the queue hint; `dispatchWorkspace` alone drives an idle accepted input to terminal (proven, no cron). Contention keeps fencing/ordering; missing models/credentials fail as `model_unavailable` with scoped text.
- Follow-ups during runs use the single Send/Stop slot with overflow Stop; two rapid sends carry distinct UUIDs; clarification answers bind their pending ID; author-only Stop stops work without undoing commits.
- Commands: cmdk server-driven slash picker (double slash is literal text), deterministic endpoint, no chat bubbles, serial control lock (overlap rejected locally), server-confirmed model/effort reconciliation, readable names with verified voice-route labels (native/transcribed/unavailable, never blanket "text only"). /model replies now describe the verified voice route.
- Streaming: bounded size+timer flush publisher (512/64-char text, 400 ms thinking, serial chain, publish-then-consume, drain honesty boolean, per-run 24k cap with one truncation marker). Short answers publish immediately; reconnects replay cursors; final rows replace transients without blanks.
- Thinking inside Working: Gemini `thinking_summaries: 'auto'` (docs-verified same-endpoint option) plus `step.start` thought snapshots; per-step block IDs; signatures stay server-side; Go adapters verified channel-less and unchanged. One nested Collapsible per run with attribution, round order, interrupted/truncated states, no empty disclosure, no Undo, excluded from tool counts and memory.
