### R04 background execution investigation, 2026-10-13

User report: a text turn usually completes while the browser remains visible, but often returns as partial after leaving and returning. - **BG01 — background actor liveness compatibility gap (P1; source confidence high, causal confidence pending).** [Configuration](../wrangler.jsonc) uses compatibility date `2026-03-24` with only `nodejs_compat`. Existing external provider fetches already have liveness protection, so this configuration gap alone does not prove why a particular run failed. Prefer the explicit flag over changing every compatibility behavior. Verify supported tooling/runtime and a real deployed hidden-tab run before claiming the symptom fixed.
- **BG02 — departure is not explicit cancellation (verified source boundary).** [ConversationScreen](../apps/web/src/ConversationScreen.tsx) closes its activity subscription when hidden; [stream cancellation](../apps/worker/src/chat/stream.ts) unsubscribes and clears its timer; [live bus](../apps/worker/src/chat/liveBus.ts) isolates listener errors. - **BG03 — lease expires across legitimate slow rounds (P1; high confidence).** [Lease default](../apps/worker/src/actor/leases.ts) is 120 seconds. The only production `renewWorkspaceLease` call is in [dispatch](../apps/worker/src/actor/dispatch.ts), after `handler.runTurn` and `completeStep`. Use one execution-owned, coarse renewal/check at phase boundaries and while an external operation is pending; stop/requeue on lost ownership, retaining existing fences and receipts. This is not per-token/publication renewal or a browser heartbeat. Background recovery must not steal a healthy long turn.
- **BG04 — observed production failure is an unfinished provider tool call (P1; observed error, departure causality unverified).** Native Chrome inspection of the existing detailed-PDF request on 2026-10-13 showed `provider_stream_error: Partial success: 13 actions committed before stream error: Responses stream completed with an unfinished tool call item.` The production transcript also shows repeated progress preambles.
